Minha Loja PWA V14.0 - Diagnóstico Supabase

Baseada na V13.9, preservando as funcionalidades existentes.

ALTERAÇÃO:
- O botão "Testar conexão" agora mostra o código HTTP e a resposta real do Supabase.
- Se for erro de rede/CORS, mostra a mensagem do navegador.
- Não altera a estrutura de vendas, estoque, usuários, backup ou sincronização.

OBJETIVO:
Identificar exatamente por que a conexão com a tabela app_backups está falhando.

Após publicar no GitHub Pages:
1. Abra a loja.
2. Vá em Mais > Backup na nuvem / configuração do Supabase.
3. Clique em Testar conexão.
4. Envie um print da mensagem que aparecer.
