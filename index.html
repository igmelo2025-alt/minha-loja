Backup e restauração

Backup e restauração

Exporte uma cópia completa dos produtos, vendas e gastos. Guarde o arquivo fora do celular para ter uma cópia segura.

Antes de restaurar ou apagar dados, o aplicativo mantém uma cópia de segurança local.

Backup automático

O aplicativo pode fazer uma cópia automática quando houver alterações novas.

O backup automático local é salvo no armazenamento do navegador. Para proteção contra perda do aparelho, ative também a nuvem.

☁️ Backup na nuvem

Escolha onde manter uma cópia fora do aparelho. O Google Drive usa a autorização oficial do Google.

O aplicativo pede somente acesso aos arquivos criados por ele. Para funcionar, o projeto Google precisa ter a Drive API habilitada e um OAuth Client ID para aplicativo Web. O endereço onde a loja estiver hospedada precisa estar cadastrado como origem autorizada.

No Supabase, use somente a chave pública anon. Nunca coloque a service_role no aplicativo.
